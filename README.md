# Prestige VTC

Site vitrine premium pour un service de chauffeur privé à Paris et en Île-de-France. Ce projet sert de portfolio professionnel et présente une expérience responsive, accessible et orientée conversion.

## Stack

- Next.js App Router
- React et TypeScript
- Tailwind CSS v4
- Lucide React
- `next/font` pour les polices optimisées par Next.js

## Fonctionnalités

- Homepage premium avec hero image et CTA
- Pages Services et Zone d’intervention
- Page Contact avec formulaire de demande préparé côté interface
- Header mobile accessible et footer global
- Metadata par page, Open Graph, sitemap et robots
- Responsive mobile, tablette et desktop

Les coordonnées présentes dans l’interface sont des placeholders de démonstration à remplacer avant publication.

## Lancement local

```bash
npm install
npm run dev
```

Le site est disponible sur [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

Pour définir l’URL canonique avant déploiement, utiliser `NEXT_PUBLIC_SITE_URL`.
